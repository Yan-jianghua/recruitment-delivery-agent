# 逐日学习与开发计划（2026-11-13 至 2026-12-31）

目标：项目在元旦（2027-01-01）之前完成，中间至少留 7 天空档。

本计划从 2026-11-13 排到 2026-12-31，共 49 天：42 天做任务，7 天是空档。它只是计划，不是完成证据。某一天是否真正做完，以测试输出、提交记录和 WORKFLOW.md 里的记录为准。

## 使用说明

- **时间投入**：按每天 5～6 小时排。上一版按每天 2～3 小时排需要 103 天；要在元旦前完成，每天的量必须翻倍，同时去掉一些非核心内容（见下面"和上一版相比去掉了什么"）。如果每天只有 3 小时左右，这份计划做不完，必须先启用文末的"砍内容预案"，或者推后截止日期。
- **空档**：每第 7 天是空档（每周四），不排新任务，共 7 天：11-19、11-26、12-03、12-10、12-17、12-24、12-31。空档按这个顺序使用：先补这一周没完成的任务；再补没弄懂的知识（重新做一遍实验）；都完成了，就休息，或者提前做下一阶段的准备，比如安装软件、开通服务。
- **讲解方式不变**：每天都按同一个顺序进行：先讲为什么，再认识用到的模块和关键字，然后写代码、写测试、提交。时间紧，所以只给关键知识点配控制台实验，其他的讲清楚就往下走。每段代码我都先在副本里验证过，再交给你。
- **每天开始时**：你说"开始今日任务"，我先核验仓库状态，再把当天的任务拆成 3～4 个小块。
- **进度检查**：每个空档结束时检查一次进度。落后超过一天，就按文末的预案砍掉内容，保证 12-30 完成最终验收。
- **需要你自己完成的事**：安装 WSL2 和 Docker（要管理员权限，还要重启电脑）、开通模型服务并充值、保管各种密钥。密钥只放在本机的 .env 或 local/ 目录里，不发到聊天里，也不提交 Git。
- **真实企业相关的部分**：真实系统接入、甲方验收和签收，都要有真实客户才能做，不在本计划内。本计划只用模拟系统完成其中的工程部分。
