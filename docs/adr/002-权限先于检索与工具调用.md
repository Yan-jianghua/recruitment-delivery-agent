# ADR-002 权限先于检索与工具调用

## 状态

规划基线。

## 背景

企业资料、订单、供应商和物流数据具有租户、部门、对象和字段级访问差异。模型输出、提示词和前端隐藏不能作为授权依据。检索后再隐藏结果可能把无权内容带入模型上下文。

## 决策

服务端先根据可信身份、租户、资源、动作和策略版本计算授权范围，再执行检索。引用打开、导出、工具调用和写入前再次校验。模型只能提出查询、解释和草稿，不能决定可见资源、权限、审批或动作。

## 结果

系统需要维护资源级 ACL、权限版本、审计事件和撤权失效路径。向量或关键词索引必须支持租户和资源过滤，采用近似索引前先验证过滤后的召回和零泄露。

## 验收

覆盖跨租户、对象越权、撤权后历史答案、恶意文档提示注入、无权引用和工具越权。任何正文泄露都阻断对应发布。
