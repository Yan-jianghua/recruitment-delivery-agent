# ADR-001 模块化单体与内网集成网关

## 状态

规划基线，待 B1 真实负载和企业网络条件复核。

## 背景

项目由一名开发者先完成业务纵向切片，需要保持模块边界清晰，同时接入企业内网系统。直接拆成多个服务会增加部署、认证、追踪和故障恢复成本。让平台直接进入客户内网也会扩大网络和凭据边界。

## 决策

API、权限、领域规则、检索、审计和任务先采用模块化单体。企业系统通过客户内网或私有云中的集成网关出站连接，平台调用版本化的最小连接器契约。只有实际负载、团队分工或安全边界证明需要时才拆分独立服务。

## 结果

开发和本地复现成本较低，权限和审计链容易串联。模块需要通过接口和测试维护边界。内网网关需要独立部署、凭据隔离、白名单、重试和状态查询。

## 复议条件

出现独立扩容需求、客户网络要求隔离运行、连接器故障影响面过大或团队分工需要独立发布时，重新评估服务拆分。
