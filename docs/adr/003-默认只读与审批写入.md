# ADR-003 默认只读与审批写入

## 状态

规划基线。

## 背景

订单、价格、供应商、单证和消息动作可能产生外部副作用。模型请求可能重复、超时或返回不完整字段。只依靠提示词要求模型谨慎无法证明写入安全。

## 决策

所有工具默认只读。低风险写入先生成预览，显示目标系统、对象、字段变化、影响范围、审批人和幂等键。执行采用 plan、preview、approve、execute、verify 流程。高风险动作需要人工审批、对象版本检查、幂等和补偿或回滚路径。

## 结果

B0 只实现查询、异常判断和动作预览。真实写入必须按动作单独验收。连接器不能暴露任意 SQL、任意 HTTP、任意脚本或生产管理员凭据。未知结果进入查询或人工对账，不能盲目重试。

## 验收

覆盖重复请求、对象版本变化、审批过期、连接器超时、错误响应、部分成功和回滚失败。审计记录保存发起人、审批人、策略版本、工具版本、结果和关联 ID。
