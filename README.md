# 招聘交付与候选人管理 Agent

英文标识采用 `recruitment-delivery-agent`。

## 项目定位

面向招聘与人力资源服务机构，把甲方职位、岗位规则、候选人授权资料、面试记录、背调结果、推荐交付和入离职状态连接起来，提供带来源的筛选、面试准备、推荐报告和受控流程待办。外贸订单履约作为第二领域包。

项目的定制价值来自企业对象模型、规则包、内部系统连接器、权限与审计链和客户专属评测集。当前仓库处于规划与设计阶段，尚无业务源代码、数据库迁移、接口测试、前端应用、CI、部署或真实企业接入证据。

## 技术方向

- Python、FastAPI、Pydantic：后端接口和输入校验。
- PostgreSQL：业务对象、权限、版本、任务和审计。
- pgvector：在授权范围内执行向量检索，使用前需要实测过滤和召回。
- React、TypeScript：检索、异常和预览页面。
- 企业 IdP、内网集成网关和版本化连接器：B1 以后接入。
- Docker、测试和 CI：复现运行环境并验证权限、恢复和契约。

## 当前边界

B0 使用合成数据完成权限治理 RAG、职位解析、候选人授权检索、规则筛选、面试包和推荐报告预览。真实企业身份、ATS/CRM/HR/OA/合同系统接入、背调和派遣写入、自动发送和安全认证均需单独设计、联调和签收。

关键架构决策见 [ADR 目录](docs/adr/)。
